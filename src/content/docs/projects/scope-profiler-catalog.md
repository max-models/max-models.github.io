---
title: Profiling catalogue
description: A searchable website template for profiling runs
---

A template for publishing profiling runs as a searchable documentation site, with charts, hotspot tables, and scaling plots generated from `scope-profiler` data.

Start with a catalogue manifest that names the profiling cases and their input files, fetch the data into the project, then generate the pages with the `scope-profiler site` command. The template includes the Astro site and deployment workflow, so each run can be browsed and compared from the resulting catalogue.

Site: [max-models.github.io/scope-profiler-catalog](https://max-models.github.io/scope-profiler-catalog/)
